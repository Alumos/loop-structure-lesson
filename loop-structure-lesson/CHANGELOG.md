# 更新记录

## v1.1.0

本次按 `loop-structure-lesson整改方案.md` 调整循环结构课堂。

- 学生从空流程图开始，自己添加开始、判断、动作、结束节点，连接普通箭头、是/否分支及返回箭头。
- 增加鼠标拖线、点击与键盘连接、节点排序、删线、撤销和清空。
- 沿学生连接的箭头解析执行顺序。缺少返回箭头、返回目标错误、断线、孤立节点、判断分支缺失或未合流时不能运行，提示说明具体问题。
- 第一、二关固定先判断；第二关把“前方危险？”与“左转 90°”拆为独立节点。
- 第三关删除“前进一格”，仅保留“到下一样点 → 扫描当前样点”。先判断时没有扫描数据，先执行时在第 8 个样点找到水冰。
- 第四关取消预填，学生自行搭建。完整方案可比较先判断 0 轮与先执行 4 轮。
- 第三、四关切换时机时保留循环体；未完成的流程图不会被自动补全。
- 运行时高亮实际经过的节点和箭头，教师端显示流程证据及是否完成同一方案的时机对照。
- 验收题、讲评和过程评价加入返回箭头；新记录保存节点与连线，不保存逐帧动画。
- 旧版方案保留教师只读回放和成绩；学生重新编辑旧草稿时从空流程图开始。

24 项单元与接口测试、4 项 Chromium 浏览器测试及 TypeScript/生产构建通过。浏览器测试覆盖手工建图、拖线、键盘连接、返回箭头校验、四关关键结果、教师实时同步、离线补传、独立验收、旧浏览器 API 兼容和移动端布局。
